# PayNXT 💳

PayNXT is a modern fintech-inspired web application designed to simulate a digital payment platform experience. The project focuses on building a clean, interactive interface inspired by real-world payment apps like PhonePe and other digital wallets.

## Live Demo

[https://swaraj808-dev.github.io/PayNXT/](https://swaraj808-dev.github.io/PayNXT/)

## Overview

PayNXT showcases a modern finance dashboard experience built to practice real-world frontend development and product-style UI design. The application emphasizes user experience, visual design, and interactive elements to replicate the feel of a real fintech product.

## Features

* Modern fintech-style interface
* Interactive payment dashboard
* Send and recharge UI pages
* Rewards and feature sections
* Clean and minimal user experience
* Multi-page navigation system

## Tech Stack

* HTML
* CSS
* JavaScript

## Project Purpose

* Practice real-world frontend development
* Improve UI/UX design skills
* Build a strong portfolio project
* Simulate a real fintech product interface
